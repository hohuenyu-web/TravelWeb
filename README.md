# JourneyCrafter 旅行規劃

個人旅行規劃網站：行程、地圖、記帳、分帳、美食、購物同資訊都可以儲存在雲端。

## 使用方法

1. 打開網站後，按右上角「新增」建立旅程。可以自訂旅行編號，或留空由系統產生。可選填「目的地」（例如曼谷），行程每日天氣會按目的地同當日日期自動連結；若預報可用會顯示高低氣溫。
2. 建立後會顯示並複製「旅行編號」。請把編號記低。
3. 之後喺任何裝置打開同一個網站，按「加入」，輸入同一個編號，就可以睇返整個行程同所有記錄。
4. 右上角圓點變綠色代表已連上雲端；紅色代表暫時離線，資料會先存在此裝置。
5. 分帳可先新增成員，記帳時勾選「誰一起分」。結算會顯示每人已付、應付、結餘，以及正確嘅轉帳方案（唔會再全部顯示同一個平均金額）。

網站會發佈喺 GitHub Pages。
