# JourneyCrafter 旅行規劃

個人旅行規劃網站：行程、地圖、記帳、分帳、美食、購物同資訊都可以儲存在此裝置，並用旅行編號與同行的人即時同步。

## 使用方法

1. 打開網站後，按右上角「新增」建立旅程。可以自訂旅行編號，或留空由系統產生。可選填「目的地」（例如曼谷），行程每日天氣會按目的地同當日日期自動連結；若預報可用會顯示高低氣溫。
2. 新增會得到旅行編號；請把編號記低或分享給同行的人。
3. 朋友在另一部裝置打開同一個網站，按「加入」輸入同一個編號即可一齊改行程。
4. 右上角綠色點代表已連上同步；紅色代表暫時離線，資料會先存在此裝置，連線後可再同步。
5. 分帳可先新增成員，記帳時勾選「誰一起分」。結算會顯示每人已付、應付、結餘，以及正確嘅轉帳方案。

封面、背景及卡片相片會留在加入相片的裝置；文字行程、景點、航班、記帳、分帳、目的地、日期和備註會同步到各裝置。

刪除行程後，呢個編號會釋出，可以重新用來建立新旅程；已加入嘅其他裝置亦會移除該行程。

網站會發佈喺 GitHub Pages。
